# 크롬 웹 스토어 등록 자료

[Chrome 웹 스토어 개발자 대시보드](https://chrome.google.com/webstore/devconsole)에 그대로 붙여 넣을 내용이에요.

## 등록 순서

1. 개발자 계정 등록 (처음 한 번, 등록비 5달러) → 2단계 인증 켜기
2. **새 항목** → 최신 릴리스의 `Convenient_BOJ-webstore.zip` 업로드
3. 업로드하면 확장 ID가 정해져요 (대시보드 주소와 항목 정보에 보여요)
   - 그 ID를 `host/install.ps1` 의 `$ExtensionIds` 에 추가하고 새 버전을 릴리스해요 (완료: `pljhagfdkkdpgjmkkdpalhdihpopjgem`, v1.6.1)
   - 그래야 스토어 버전도 내 PC 실행 도우미에 연결돼요 (스토어에 올린 ZIP은 다시 올릴 필요 없어요)
4. 아래 **스토어 등록정보 / 개인정보 보호 관행** 탭을 채우고 이미지를 올려요
5. **검토를 위해 제출** → 보통 며칠 걸려요. `nativeMessaging` 권한이 있어 조금 더 걸릴 수 있어요

### 상세 설명

```
백준(acmicpc.net) 문제 화면에서 문제 읽기 → 코드 작성 → 실행 → 제출 → 정/오답 확인을 한 화면에서 끝내는 확장 프로그램이에요.
※ 백준·스타트링크·데이원컴퍼니와 관련 없는 비공식 확장 프로그램이에요.

■ 분할 화면
· 문제 페이지에서 [⇆ 코드 작성] 버튼이나 Alt+C로 열어요. 왼쪽은 문제 그대로, 오른쪽은 코드 에디터와 결과·터미널이에요.
· 작성한 코드는 문제·언어별로 자동 저장되고, 다시 열면 마지막 위치로 돌아가요.

■ 6개 언어 실행: C · C++ · Java · Rust · Python 3 · PyPy3
· [실행](Ctrl+Enter)을 누르면 예제와 나만의 테스트케이스로 채점해요.
· 틀리면 몇 번째 줄부터 다른지 표로 강조해서 보여 줘요. 컴파일 에러·런타임 에러·시간 초과도 그대로 보여 줘요.
· 컴파일 옵션과 컴파일러 버전을 백준에 맞췄어요. (예: Java는 --release 11, Rust는 rustc --edition 2021 -O, PyPy3는 진짜 PyPy로 실행)

■ 진짜 터미널 (선택, Windows)
· 내 PC 실행 도우미를 설치하면 코드를 내 PC에서 실행하고, VS Code 터미널처럼 실행 중에 입력을 주고받아요.
· 팝업의 [도우미 받기]로 받아 install.bat을 더블클릭하면 돼요. 설치하지 않으면 온라인 컴파일러 Wandbox에서 실행돼요.

■ 제출과 채점 결과
· [제출]을 누르면 백준의 공식 제출 페이지가 옆 탭에 열리고 코드와 언어가 채워져 있어요.
· 백준의 [제출] 버튼은 직접 눌러요. (백준 이용 규칙과 reCAPTCHA 때문에 자동 제출은 하지 않아요)
· 제출하면 원래 탭으로 돌아오고, 채점 결과가 실시간으로 표시돼요. 채점이 끝나면 제출 탭은 저절로 닫혀요.

■ VS Code 같은 편집
· 자동완성: 점(.)만 쳐도 많이 쓰는 멤버부터 보여 주고, 글자를 건너뛰어도 찾아요 (pb → push_back)
· 엔터 자동 들여쓰기, 탭/공백 4칸 선택, 괄호 자동 닫기
· 언어별 기본 코드(팝업에서 수정), 밝은/어두운 테마, 풀이 타이머

■ 개인정보
· 개발자는 어떤 정보도 수집하지 않아요. 코드와 설정은 내 브라우저에만 저장돼요.
· 내 PC 실행 도우미 없이 실행하면 코드와 입력이 Wandbox(wandbox.org)로 보내져요.
· 개인정보처리방침: https://github.com/gaudium1257/Convenient_BOJ/blob/main/PRIVACY.md

소스 코드(MIT): https://github.com/gaudium1257/Convenient_BOJ
```

## 개인정보 보호 관행

### 단일 목적
```
백준 온라인 저지(acmicpc.net) 문제 페이지에서 코드를 작성하고, 실행해 예제와 비교하고, 백준 공식 제출 페이지로 제출한 뒤 채점 결과를 확인하는 과정을 한 화면에서 할 수 있게 해 주는 것.
```

### 권한별 사유

**storage**
```
사용자가 작성 중인 코드(문제·언어별), 커서 위치, 나만의 테스트케이스, 풀이 타이머, 설정(테마·들여쓰기·언어별 기본 코드)을 브라우저에 저장하고, 백준 제출 페이지에 채워 넣을 코드를 잠시 보관하는 데 씁니다.
```

**nativeMessaging**
```
사용자가 따로 설치하는 선택 기능인 '내 PC 실행 도우미'(Windows, 오픈 소스 Python 스크립트)와 통신해 코드를 사용자 PC에서 컴파일·실행하고, 실행 중인 프로그램과 표준 입출력을 주고받는 데 씁니다. 도우미를 설치하지 않으면 이 권한은 연결 실패만 확인하고 아무 일도 하지 않습니다.
```

**호스트 권한 (https://wandbox.org/*)**
```
사용자가 [실행]을 눌렀을 때, 내 PC 실행 도우미가 없으면 공개 온라인 컴파일러 Wandbox의 API로 코드와 예제 입력을 보내 컴파일·실행 결과를 받습니다. 사용할 컴파일러 버전을 고르기 위해 컴파일러 목록도 읽습니다.
```

**콘텐츠 스크립트 (acmicpc.net 의 /problem/*, /submit/*, /status*)**
```
문제 페이지에 분할 화면(에디터·결과)을 붙이고 예제 입출력을 읽습니다. 제출 페이지에서는 사용자가 작성한 코드와 언어를 채워 넣고(제출 버튼은 사용자가 직접 누름), 채점 현황 페이지에서는 방금 제출한 코드의 채점 결과를 읽어 분할 화면에 보여 줍니다.
```

**대시보드의 "호스트 권한" 칸** (위 두 가지를 한 칸에 묻는 경우)
```
· acmicpc.net 의 /problem/*, /submit/*, /status* : 문제 페이지에 분할 화면(코드 에디터·실행 결과)을 붙이고 예제 입출력을 읽습니다. 제출 페이지에는 사용자가 작성한 코드와 언어를 채워 넣기만 하고, 제출 버튼은 사용자가 직접 누릅니다. 채점 현황 페이지에서는 방금 제출한 코드의 채점 결과를 읽어 분할 화면에 보여 줍니다.
· wandbox.org : 사용자가 [실행]을 눌렀을 때, 내 PC 실행 도우미가 없으면 공개 온라인 컴파일러 Wandbox의 API로 코드와 예제 입력을 보내 컴파일·실행 결과를 받습니다.
이 두 사이트 외에는 접근하지 않습니다.
```

### 원격 코드
**아니요, 원격 코드를 사용하지 않습니다.** (CodeMirror를 포함한 모든 스크립트가 패키지 안에 있어요)

### 데이터 사용
수집하는 데이터 유형에서 **"웹사이트 콘텐츠"**만 체크하는 걸 권해요.
- 이유: 도우미가 없을 때 사용자가 작성한 코드와 문제의 예제 입력(페이지의 텍스트)을 Wandbox로 보내 실행하기 때문이에요. 개발자에게는 아무것도 오지 않지만, 외부 서비스로 보내는 경우도 공개 대상이에요.
- 나머지(개인 식별 정보, 인증 정보, 웹 기록, 사용자 활동 등)는 체크하지 않아요.

아래 세 가지는 모두 체크해요 (사실이에요).
- 승인된 사용 사례 외에 사용자 데이터를 제3자에게 판매하거나 전송하지 않음
- 항목의 단일 목적과 관련 없는 목적으로 사용자 데이터를 사용하거나 전송하지 않음
- 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않음
